# ANOVIX AI

ANOVIX AI is a lightweight desktop productivity assistant designed for students and general users.

## Features
- Notes management
- Focus timer
- System status monitoring
- WhatsApp automation (permission-based)
- Voice recognition (manual, privacy-first)
- Settings control panel

## Privacy
- No camera access
- No background listening
- All sensitive features are permission-gated

## Platform
- Windows only

## Installation
Download the EXE from the Releases section and run it directly.
